# 龙心 · 手机阅读测试版

仅内置功能说明，不包含原作正文。TXT、草稿和备份导入均只保存在当前浏览器；本版无云端同步、无离线缓存。

## 新增功能

- 三层书架：时间轴（元年／一千／两千）→ 分卷或书名 → 章节。建立分卷时可多选时间轴，同一分卷在各入口共用完整目录、批注与阅读进度；上下章按全卷序号衔接，可跨章节时间轴，不会跨到另一分卷。
- 每章填写自己的时间轴与全卷序号；分卷可改名、调整时间轴入口及移除空卷。旧版文章保留原 ID、正文与批注，在原时间轴的“待分卷”中显示；编辑章节即可归入书名。
- Word 富文本粘贴：保留段落、标题、粗斜体、下划线、颜色、列表与对齐；移除脚本、Word XML 和任意外部内容。内嵌图片暂不导入。
- 多图背景图库：本机 IndexedDB 保存图片，按分卷记住选择；可调纸色遮罩和背景模糊。
- 章节批注：底部“选句批注”可点选整句，也支持长按拖选；选字时保持选区并避免误翻页。支持引用高亮、定位、编辑、删除、章节随记和导出；原文修改后尝试按引用重新定位。
- 文稿 JSON 备份包含时间轴、共享分卷关系、富文本和批注；兼容旧版备份。旧格式导入后归入原时间轴的“待分卷”。不包含背景原图。

## 网页上传与发布

1. 解压本压缩包。进入 GitHub 仓库，选择 uploading an existing file（上传现有文件）。
2. 把解压后的文件和 assets、source 文件夹一起拖入；index.html 必须直接在仓库根目录，不能多套一层文件夹。提交到 main。
3. 打开仓库 Settings → Pages，Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。
4. 等 GitHub 完成 Pages 部署后，打开 Pages 页面显示的真实网址，再用手机测试。

## 维护源代码

source/ 保存源码，assets/ 和根目录 index.html 是已构建成品。需要 Node.js 22.13 或更新版本。运行 npm install，然后 npm run build，输出在 build-output/；更新网站时将该目录内容复制到仓库根目录。

运行 `npm test` 检查正文选区保持、点选跨格式句子、引用保存、高亮及移动端 caret API 兼容，以及旧文稿迁移、共享分卷、跨时间轴顺序阅读、分卷隔离、重命名及新旧备份往返。自动测试使用模拟 DOM，不替代手机实测。

## 测试范围

检查手机访问、左右翻页、字号、行距、纸色、时间轴下的分卷入口和同一浏览器中的进度恢复。删除网站数据可能导致本机文章丢失，请保留原稿并定期导出备份。

## 云端第一阶段：作者账号与权限

Supabase 项目：`ydauxndnzzmwqedpzuxz`。`source/public/cloud-config.json` 仅包含浏览器可用的项目 URL 和 publishable key；禁止放入 secret key、service_role 或数据库密码。

当前阶段仅接入连通检查、邮箱密码登录、会话恢复、退出和作者名单核验。文章、分卷、批注与背景仍使用浏览器本机存储，尚未迁移或公开共享；界面会明确显示这一状态。登录不会触发本机数据迁移，退出也不会清除本机文稿。

作者账号设置：

1. 在 Supabase 项目的 Authentication → Users 中创建自己的站点用户，自行设置密码并确认邮箱（后台创建时可使用自动确认）。Supabase 管理后台账号与本项目 Auth 用户相互独立。
2. 由项目管理员核对用户邮箱或 UUID，再将对应 `auth.users.id` 加入 `public.longxin_authors`。网页客户端没有修改作者名单的权限；不提供“首位注册者自动成为作者”的入口。
3. 打开书房上方“作者登录”，使用站点邮箱和密码登录，检查“作者权限已核验”。

`public.longxin_cloud_version()` 是无数据权限的连通探针。`longxin_authors` 启用 RLS，仅允许登录用户读取自己的名单记录。后续正文读写策略必须在数据库中检查作者名单，不能依赖页面按钮、缓存状态或 user_metadata。

迁移脚本保存在 `supabase/migrations/`，文件版本与已应用的远端迁移历史对齐。依赖版本固定，并保留 package-lock.json。运行 `npm ci`、`npm run typecheck`、`npm test`、`npm run build` 后，把 build-output 的内容同步到仓库根目录部署。自动测试使用模拟 DOM；真实作者登录待账号创建后验证。
